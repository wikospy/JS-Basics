# Level 1 - JavaScript Basics

## Lessons

These lessons intentionally combine closely related syntax:

1. [Variables, data types, operators, and conversion](./01-variables.js)
2. [Conditionals and loops](./02-conditionals-and-loops.js)
3. [Functions](./03-functions.js)
4. [Arrays and objects](./04-arrays-and-objects.js)
5. [`map()`](./05-map.js)
6. [`filter()`](./06-filter.js)
7. [`reduce()`](./07-reduce.js)
8. [Other array methods](./08-other-array-methods.js)
9. [Destructuring](./09-destructuring.js)
10. [Spread and rest](./10-spread-and-rest.js)

`let`, `const`, and variable naming belong together. Array transformations such
as `map()`, `filter()`, and `reduce()` are separate because they require
different reasoning and are used constantly in frontend applications.

## Level project

Build a browser-based **personal reading tracker** with plain JavaScript.
Represent books as objects in an array, add and remove books, mark books as
finished, calculate reading statistics, and render a text summary. No libraries,
classes, or API calls are needed yet. You must use variables, functions,
conditionals, loops, objects, arrays, and array methods.

Before asking AI for help, write the data shape and the user actions in your
own words.
